Inventory hotkeys

Install into your existing Chrome or Edge WebBreak Overrides folder. Your settings, other plugins and existing inventory keys are preserved. A backup is created before updating.

Choose your Overrides folder to begin.

After installation, open www.starbreak.com/VR1574197275.mvmmoclient.js in your Overrides folder. Find SBPE INVENTORY HOTKEYS and edit its SLOT_KEYS block. Keys start unassigned.

Example: 1: "KeyZ", 2: "KeyX", 3: "Digit1". Save and reload StarBreak when ready. Keep DevTools open for Overrides.

For first-time setup, open StarBreak DevTools → Sources → Overrides, select an empty folder and click Allow. Choose that same folder here. See README.md for the full tutorial.
